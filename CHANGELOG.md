# Changelog

All notable changes to Black Whale Lab are documented here.

## [0.1.3] - 2026-08-14

### Added

- Real DeepSeek Harness Web profile integration through a DSH bundle patch.
- Black whale and Xiaoyao laboratory artwork passed through the official Web canvas.
- Reversible focus mode and scoped brand chrome.
- Runtime contrast guard for light-background/light-text controls.
- Opaque fallbacks for browsers without `backdrop-filter` support.
- English and Chinese installation documentation.

### Verified

- DeepSeek Harness `0.1.0-rc.6` with Node.js 24.
- Official Host transport, persisted sessions, workspaces, models, settings and plugin inventory.
- No model request or session mutation is performed by the skin.
